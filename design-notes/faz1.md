# FAZ-1: Robot Modeli

## 1. Problem
Simülasyonda kullanılacak temel robot modelini oluşturmak.

## 2. Gereksinimler
- Gazebo'da spawn edilebilmeli
- Üzerine sensör eklenebilecek şekilde genişletilebilir olmalı
- Çoklu robot (FAZ sonrası) için parametrik/isimlendirilebilir olmalı

## 3. Alternatifler
- Sıfırdan URDF yazmak vs hazır bir diferansiyel-sürüşlü robot 
  paketini (örn. turtlebot3 modeli) temel almak

## 4. Başarı Kriteri
Robot Gazebo'da spawn oluyor, RViz'de görünüyor, çökme/hata yok.

## 5. Sonuç
✅ **Başarılı**
